# LocationParser バグ修正レポート

**作成日**: 2026-01-11
**対象ファイル**: `LocationParser.js`
**テスト結果**: 209/210 (99.5%)

---

## 1. 問題の概要

### 発生していた問題

CSVインポート後、ダッシュボードで群馬県のデータを表示すると、東京都の「北区」「中央区」のデータが混入して表示されていた。

### 根本原因

`TOKYO_WARD_ALIASES` に危険な短いエイリアスが存在していた：

```javascript
// 問題のあったコード（削除済み）
'中央': '中央区',
'北': '北区',
'港': '港区'
```

これにより、「中央病院」「北町」「港商店」などの文字列が誤って「中央区」「北区」「港区」に変換されていた。

---

## 2. 修正内容

### 修正1: 危険なエイリアスの削除（前回セッション）

`TOKYO_WARD_ALIASES` から危険なエイリアスを削除：

| 削除したエイリアス | 理由 |
|-------------------|------|
| `'中央'` | 「中央通り」「中央病院」などに誤マッチ |
| `'北'` | 「北町」「北口」などに誤マッチ |
| `'港'` | 「港町」「港商店」などに誤マッチ |

### 修正2: 東京都 vs 京都府の部分文字列問題

**問題**: 「東京都」が「京都府」に誤認識される

**原因**: `DESIGNATED_CITY_ALIASES` に `'京都': '京都市'` が存在し、「東京都」の中に「京都」が部分文字列として含まれている

**修正箇所**: `tryValidatedLocationMatch` 関数 Section 4（行383-387）

```javascript
// 🔴 重要: 「京都」は「東京都」の部分文字列なので、特別処理が必要
// 「東京」を含む場合は「京都」のマッチをスキップ
if (alias === '京都' && text.includes('東京')) {
  continue;
}
```

### 修正3: 政令指定都市の同名区優先度問題

**問題**: 「札幌市中央区」が「中央区」（東京都）として認識される

**原因**: Section 1 で東京23区のチェックが政令指定都市より先に実行されていた

**修正箇所**: `tryValidatedLocationMatch` 関数 Section 1（行284-303）

```javascript
// 🔴 政令指定都市名が含まれるかチェック（東京23区チェックをスキップするため）
const hasDesignatedCityName = Object.keys(DESIGNATED_CITY_WARDS).some(
  cityName => text.includes(cityName)
);

// 1. 東京23区をチェック（区名から東京都を確定）
// ※ 政令指定都市名（札幌市、さいたま市等）が含まれる場合はスキップ
if (!hasDesignatedCityName) {
  for (const ward of Object.keys(TOKYO_WARDS_MAP)) {
    // ...
  }
}
```

### 修正4: 東京区エイリアス変換の適用

**問題**: 「渋谷」→「渋谷区」などのエイリアス変換が動作していない

**原因**: `TOKYO_WARD_ALIASES` が定義されているが、`tryValidatedLocationMatch` で使用されていなかった

**修正箇所**: `tryValidatedLocationMatch` 関数 Section 5（行441-457）

```javascript
// 5. 東京23区の省略形エイリアスをチェック（「渋谷」→「渋谷区」など）
// ※ TOKYO_WARD_ALIASESを使用
const sortedWardAliases = Object.keys(TOKYO_WARD_ALIASES).sort(
  (a, b) => b.length - a.length
);
for (const alias of sortedWardAliases) {
  if (text.includes(alias)) {
    const ward = TOKYO_WARD_ALIASES[alias];
    return {
      originalText: text,
      regionBlock: '関東',
      prefecture: '東京都',
      cityType: '東京23区',
      cityWard: ward,
      stationName: extractStationName(text),
      isComplete: true
    };
  }
}
```
